Introduction

The Monetz API lets you connect client projects to our platform for deployments, monitoring, and billing — the same tools we use internally, exposed for teams that want to automate their own workflow.

💡 New here? Start with Installation, then Authentication before making any requests.

Installation

Install the CLI via npm or use the REST API directly with any HTTP client.

bash 
npm install @monetz/cli --save-dev

Verify the install:

bash 
monetz --version

Authentication

All requests require an API key passed in the Authorization header. Generate a key from your dashboard under Settings → API Keys.

bash 
curl https://api.monetz.io/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY"
⚠️ Never expose your API key in client-side code. Use a server-side proxy for browser requests.

Making Requests

The API returns JSON for every endpoint. Here's a typical project lookup:

json 
{
  "id": "proj_8f3a1c",
  "name": "Client Landing Page",
  "status": "deployed",
  "created_at": "2026-01-14T10:22:00Z"
}

Webhooks

Subscribe to deployment and billing events by registering a webhook URL in your dashboard. Payloads are signed so you can verify authenticity.

json 
{
  "event": "deployment.completed",
  "project_id": "proj_8f3a1c",
  "timestamp": "2026-01-14T10:24:11Z"
}

Rate Limits

Requests are limited to 120 per minute per API key. Rate limit status is returned on every response via headers.

http 
X-RateLimit-Limit: 120
X-RateLimit-Remaining: 114
X-RateLimit-Reset: 1737000000

Error Codes

Errors follow a consistent shape across every endpoint.

json 
{
  "error": {
    "code": "invalid_api_key",
    "message": "The provided API key is invalid or expired."
  }
}
