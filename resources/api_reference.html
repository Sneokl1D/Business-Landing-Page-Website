GET /v1/projects

List Projects

Returns a paginated list of every project associated with your account.

ParamTypeDescription
limit integer Number of results per page. Default 20, max 100.
status string Filter by status: draft, deployed, or archived. 
curl https://api.monetz.io/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY"
{
  "data": [
    {
      "id": "proj_8f3a1c",
      "name": "Client Landing Page",
      "status": "deployed"
    }
  ],
  "has_more": false
}
POST /v1/projects

Create Project

Creates a new project under your account.

ParamTypeDescription
namerequired string Display name for the project.
repo_url string Git repository to link, if any. 
curl -X POST https://api.monetz.io/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"name":"New Landing Page"}'
{
  "id": "proj_2b91ff",
  "name": "New Landing Page",
  "status": "draft"
}
DEL /v1/projects/:id

Delete Project

Permanently deletes a project and all associated deployments. This cannot be undone.

ParamTypeDescription
idrequired string The project ID, passed in the URL path. 
curl -X DELETE https://api.monetz.io/v1/projects/proj_8f3a1c \
  -H "Authorization: Bearer YOUR_API_KEY"
{
  "deleted": true,
  "id": "proj_8f3a1c"
}
POST /v1/deployments

Trigger Deployment

Starts a new deployment for the given project's latest commit.

ParamTypeDescription
project_idrequired string The project to deploy.
branch string Branch to deploy. Defaults to main. 
curl -X POST https://api.monetz.io/v1/deployments \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"project_id":"proj_8f3a1c"}'
{
  "id": "dep_44a1",
  "status": "in_progress",
  "project_id": "proj_8f3a1c"
}
GET /v1/deployments/:id

Get Deployment

Returns the current status and logs for a single deployment.

ParamTypeDescription
idrequired string The deployment ID, passed in the URL path. 
curl https://api.monetz.io/v1/deployments/dep_44a1 \
  -H "Authorization: Bearer YOUR_API_KEY"
{
  "id": "dep_44a1",
  "status": "completed",
  "duration_ms": 8421
}
POST /v1/webhooks

Create Webhook

Registers a URL to receive event notifications for your account.

ParamTypeDescription
urlrequired string HTTPS endpoint to receive event payloads.
events array Event types to subscribe to. Defaults to all. 
curl -X POST https://api.monetz.io/v1/webhooks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"url":"https://example.com/hook"}'
{
  "id": "wh_9931",
  "url": "https://example.com/hook",
  "events": ["deployment.completed"]
}
PUT /v1/webhooks/:id

Update Webhook

Updates the URL or subscribed events for an existing webhook.

ParamTypeDescription
idrequired string The webhook ID, passed in the URL path.
url string New endpoint URL. 
curl -X PUT https://api.monetz.io/v1/webhooks/wh_9931 \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{"url":"https://example.com/new-hook"}'
{
  "id": "wh_9931",
  "url": "https://example.com/new-hook"
}
